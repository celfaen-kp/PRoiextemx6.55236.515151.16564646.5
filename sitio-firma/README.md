# Página de aceptación y firma de presupuestos · Sysefen

Sitio estático para `firma.sysefengroup.com`: una sola página que lee el presupuesto
por su enlace (`?t=…`) desde la función `presupuesto-cliente` de Supabase y manda la
firma. No lleva nada de la app. Se publica con GitHub Pages desde la rama `main`.
